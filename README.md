# Local AI Chatbot on Raspberry Pi + AI HAT 2

## Overview
A local/edge AI portfolio project built around a **Raspberry Pi with AI HAT 2** to explore running an AI chatbot locally rather than depending entirely on cloud inference.

The project focuses on edge computing, privacy, resource-constrained AI deployment, Linux administration, model/runtime integration, and performance testing.

## Skills Demonstrated
- Raspberry Pi / Linux
- Edge AI and local inference
- AI accelerator integration
- Python application development
- Local service/API concepts
- Resource and performance monitoring
- Privacy-focused system design
- Troubleshooting

## Project Goals
- Run chatbot inference locally on Raspberry Pi hardware.
- Explore AI HAT 2 acceleration capabilities.
- Measure CPU, memory, latency, and accelerator behavior.
- Keep supported interactions/data local where possible.
- Document deployment limitations and optimization work.
